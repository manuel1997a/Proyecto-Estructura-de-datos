# Proyecto-Estructura-de-datos
Analizador estadístico de calidad. Proyecto #19

Lo que hace:
Formulario: Metes datos de la muestra: nombre de la fruta, variedad, temperatura, humedad (%), pH del suelo, lluvia (mm) y calidad observada (0-100).
Validación: No deja meter tonterías, valida que humedad sea 0-100, pH 0-14, lluvia no negativa y calidad 0-100.
Tabla: Cada muestra que registras se guarda en la tabla de la derecha.
Funciones: Puedes eliminar la muestra seleccionada, limpiar los campos y calcular el promedio de calidad de todas las muestras registradas.
